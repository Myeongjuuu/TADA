# Local data (not distributed)

```text
data/source/ds005574/
  derivatives/ecogprep/sub-XX/ieeg/sub-XX_task-podcast_desc-highgamma_ieeg.fif
  stimuli/podcast_transcript.csv
  stimuli/gpt2-xl/transcript.tsv
  stimuli/gpt2-xl/features.hdf5  # layer-24

data/ecog_caches/               # generated by prepare_* scripts
```

Dataset: https://openneuro.org/datasets/ds005574 . The downloader
fetches public derivatives and stimuli, not raw EDF files. Observe the dataset's
access/attribution/license terms; inputs and their transcripts are not bundled.
All preparation paths can be overridden with CLI arguments.

The functional electrode mask is fetched from the pinned Podcast Benchmark
revision by `python scripts/fetch_electrode_metadata.py`. It is not inferred
from this project's test-fold encoding scores. Do not substitute a different
electrode list for strict replication.

Participants: sub-01, sub-03, sub-04, sub-05, sub-06, sub-07, sub-08, sub-09.
Public sub-02 is absent from the selected electrode mask.
