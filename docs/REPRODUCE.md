# Reproduction

Run commands from the repository root. Installation instructions are in the
[README](../README.md); input filenames are in [data/README.md](../data/README.md).

## 1. Data and neural caches

```bash
bash scripts/download_official_preprocessed.sh data/source/ds005574
python scripts/fetch_electrode_metadata.py
python scripts/run_experiments.py --stage prepare
```

The electrode CSV is pinned to the revision and SHA-256 in
`fetch_electrode_metadata.py`. The dataset downloader uses the upstream
OpenNeuro `main` tree; exact replication requires the corresponding source
snapshot. The environment dependencies specify compatibility bounds rather
than the exact historical training versions.

Preparation runs three scripts:

| Script | Cache | Response representation |
|---|---|---|
| `prepare_srm_cnn_cache.py` | `heo2026_625ms_sw200_t10` | 625-ms extent centered at +150 ms, ten overlapping 200-ms bins |
| `prepare_multiwindow_cache.py` | `heo2026_multiwindow_t10` | 250/625/1500-ms extents, 80/200/400-ms smoothing, ten bins per window |
| `prepare_lag_cache.py` | `wide_m1000_p1000` | -1 to +1 s in forty bins |

Short, medium and long windows span +25 to +275 ms, -162.5 to +462.5 ms,
and -600 to +900 ms. The lag cache obtains canonical word IDs from the row
indices of `podcast_transcript.csv`.

Use `--source-root`, `--electrode-file` and `--cache-root` on the runner to
reuse external data and cache directories. `--cache-root` denotes the parent
directory containing the three caches above.

## 2. Figure 1

```bash
python scripts/run_experiments.py --stage figure
```

The analysis predicts significant-electrode responses from GPT-2 XL layer-24
features using training-fold PCA50 and ridge regression. A 200-ms response
window advances in 50-ms steps; ridge alpha is 100 after scaling. Five
chronological folds measure held-out Pearson correlation. Outputs are written
to `results/lag_encoding/` and `results/figures/`.

To render the included reference results as SVG without scientific packages:

```bash
python scripts/plot_lag_resolved_encoding_svg.py --output results/figures/reference_encoding.svg
```

The SVG script also accepts `--results-dir results/lag_encoding` for a new run.

## 3. Train and evaluate the seven table methods

```bash
python scripts/run_experiments.py --stage decoding --device cuda
```

Or run one stage at a time:

```bash
python scripts/run_experiments.py --stage pca
python scripts/run_experiments.py --stage srm-cnn
python scripts/run_experiments.py --stage medium
python scripts/run_experiments.py --stage long
python scripts/run_experiments.py --stage multi
python scripts/run_experiments.py --stage egr
```

The PCA stage evaluates both PCA and PCA+HA. All stages default to eight
held-out participants and five chronological folds. Source participants train
the decoder; held-out training responses estimate the unsupervised projection.
Default target PCA is 50 components, SRM dimensionality is five with 100
iterations, maximum epochs is 100, patience is ten, and seed is zero.

EGR trains/evaluates the base decoder and ridge encoder in the same run.
Source validation selects ridge alpha and fusion weight. Re-ranking does not
update decoder weights.

For a small execution check after cache preparation:

```bash
python scripts/run_experiments.py --stage decoding --held-out-subjects 03 --max-words 120 --epochs 1 --patience 1 --outer-folds 2 --device cpu --output-root results/smoke
```

These debugging limits change the experiment and must be omitted for paper
results. Full evaluation uses all eight held-out configurations and five folds.

## 4. Tables and statistical tests

Recompute the included reference tables and check all 140 printed mean/SD
values against the manuscript:

```bash
python scripts/summarize_paper.py --check-manuscript
```

For a complete new run generated by the runner:

```bash
python scripts/summarize_paper.py --layout run --results-root results --output-dir results/tables
python scripts/analyze_statistics.py --results-root results
```

`--layout reference` is the default and reads the included reference result
directories. `--layout run` reads the new `pca`, `srm_cnn`, `medium`, `long`,
`multi` and `egr` directories. The two layouts are never mixed.

Each source result is averaged across source participants and folds within
a held-out configuration, then summarized across eight configurations. SD is
sample SD. Held-out participants are the independent units for two-sided exact
paired sign-flip tests. Holm correction covers the three temporal AUC
comparisons; EGR is tested against its same-run base decoder separately.
